[实验模板](TEMPLATE.md) 建立独立记录。

## 必填证据

每个实验至少记录：

- 运行 ID、项目、工作区、状态、开始时间和时长。
- 模型配置、参数量和代码提交。
- 数据 Manifest、Content Hash、样本数与 Token 数。
- 优化器、调度器、Batch、上下文长度、精度和设备。
- Train / Validation 曲线与导出路径。
- 最终 Step、最终指标、Checkpoint 和推理产物。
- 结论、异常、限制和复现命令。

## 事实规则

1. 平台截图读数只能标记为“近似”，不能补成精确小数。
2. 没有原始 JSON、Manifest 或日志支持的指标写“待补充”。
3. 计划中的训练阶段不得写进“已完成实验”。
4. 预训练基座不得描述为 Chat / SFT / 对齐模型。
5. 图表、日志和完整指标文件应放在稳定归档位置，而不是只依赖临时链接。

## 命名

```text
YYYY-MM-DD-<model>-<stage>-<short-run-name>.md
```
