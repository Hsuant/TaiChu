## 1. 实验目标

使用 TaiChu-80M Dense 配置完成一次从数据、训练、恢复到评估的公开预训练运行，
验证以下链路：

```text
Binary Dataset
  → Packing / Batch
  → TaiChuModel
  → AdamW + WSD
  → Checkpoint
  → Validation / Generation
  → SwanLab
```

本实验不包含 SFT、偏好优化、RLHF、Agent 或下游能力评测。

## 8. 结论

**已验证**

- 80M 预训练能够在真实训练环境持续约 22 小时并正常结束。
- 训练 Loss 在约前 5k Step 快速下降，随后进入低幅波动平台。
- Warmup-Stable-Decay 轨迹可见。
- Checkpoint 恢复与 SwanLab 续写链路可工作。

**不能声称**

- 模型已具备稳定指令遵循能力。
- 模型已完成 SFT / DPO / RLHF / Agent 训练。
- 模型在 C-Eval、MMLU、HumanEval 等 Benchmark 上达到某个分数。
- 多卡 NCCL 或目标加速器训练已经稳定。

## 9. 复现命令

```powershell
python -m trainer.train_pretrain `
  --model_config configs/TaiChu_80M.yaml `
  --pretrain_config configs/train_pretrain_80m.yaml
```

从已有完整 Checkpoint 续训：

```powershell
python -m trainer.train_pretrain `
  --model_config configs/TaiChu_80M.yaml `
  --pretrain_config configs/train_pretrain_80m.yaml `
  --resume <experiment-dir>/checkpoints/checkpoint-26000.pt
```

公开复现前必须修正数据绝对路径和 Dataset ID 不一致问题，见
[配置指南](../CONFIGURATION.md#5-当前路径与身份问题)。
